# Documentation Map

This project keeps documentation in four folders:

1. `docs/engineering` - implementation decisions, architecture notes, and phase status.
2. `docs/plan` - delivery roadmap and phase-by-phase execution intent.
3. `docs/go-and-gin` - Go and Gin concepts actively used in this codebase.
4. `docs/setup` - local setup, environment variables, and endpoint usage.

Read in this order for onboarding:

1. `docs/setup/README.md`
2. `docs/go-and-gin/README.md`
3. `docs/engineering/README.md`
4. `docs/plan/README.md`
